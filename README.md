Entry for the make.fun bounty [Two Lines to Your Past Self](https://make.fun/bounty/u-suga-two-lines-to-your-past-self-f36c83ca).

`main.py` (Python 3.13, standard library only) writes two lines to
`/output/entry.txt`: line one warns a past self about one specific moment,
line two says why that moment mattered and what changed because of it.

Run it with:

```sh
python3 -P -s main.py
```
